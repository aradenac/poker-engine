Garanties d’activation

  • Tous les composants sont téléchargés puis contrôlés avant l’installation.
  • L’activation bascule la version active en une seule opération ; une erreur conserve la version précédente.
  • Les caches sont isolés par identité de pack et révision runtime, ce qui empêche le mélange de générations.
  • Le Service Worker ne remplace que les composants déclarés par la version active ; les personnalisations Hero restent indépendantes.
  • Une version incompatible avec l’application ne peut pas être activée.
