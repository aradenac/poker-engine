Sans modèle population, les ranges sources importées restent utilisées.
En mode Hand History, le modèle population filtre la distribution des 169 mains au fil des actions préflop réellement observées. Si un joueur n'a encore effectué aucune action volontaire, ou si aucun nœud exploitable n'est trouvé, la range source importée reste la source de repli.
Modèle population postflop non chargé
Aucun modèle postflop chargé.
Sans modèle postflop, les ranges adverses estimées restent conditionnées uniquement par le préflop.
Le modèle population maintient une distribution persistante sur les 1326 combos exacts dès le préflop, puis la conditionne après chaque action jusqu’à la river. Les cartes publiques retirent immédiatement les combos bloqués. Board, SPR et prix de la mise adverse sont traités par le modèle postflop. Le bouton « Range adverse » affiche l’état estimé à l’étape courante.

Résultat d’équité

Le recalcul se lance automatiquement dès que la configuration est complète.
L’équité de showdown reste une probabilité brute : le rake ne change pas la probabilité de gagner. Dans le replayer, le rake réel indiqué par la Hand History est déduit du pot (au taux effectif de la main, proratisé à la taille du pot) pour calculer les seuils de rentabilité, l’EV des calls et les verdicts.
